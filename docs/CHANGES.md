# Changes in the corrected submission package

This revision supersedes the earlier numerical tables and simulation CSVs. All numbers used in the revised manuscript are generated from the enclosed corrected implementation with newly documented random-number streams.

1. **Removed use of unavailable covariates.** Incomplete-data spline knots are fitted only to observed complete-record L2 values. The full-data benchmark has its own basis. Observed-data prediction and augmentation use explicit response-pattern subsets, allowing truly missing values and avoiding `0 * NaN` calculations.
2. **Corrected response-oracle diagnostics.** True response probabilities now enter causal-regression training weights, training pseudo-outcomes, and final validation augmentation. The earlier option changed only final validation probabilities.
3. **Corrected the efficiency statistic.** Primary and bootstrap reductions use centered empirical variances. Squared deviations from the true ATE remain correctly labeled as MSE/RMSE.
4. **Separated coarsened oracle projections.** The primary oracle study retains the full-law-Q0 diagnostic and also reports the complete-case-Q0 alternative. The all-oracle crossfit check uses the complete-case conditional projection. Their equality of population means outside common validity is explained; they are not claimed to be feasible estimators of the causal ATE in that setting.
5. **Added a prospective bounded-propensity design.** Treatment probabilities lie in approximately [0.269,0.731], with bounded outcomes, the same sequential response mechanisms, and an exactly known ATE of 0.15. All nuisance functions are estimated in 4,000 replicates across two sample sizes and two scenarios.
6. **Regenerated all numerical evidence.** The archive contains 14,500 estimated-nuisance/diagnostic samples, 4,000 primary oracle samples, and 30,000 sensitivity samples, with all replicate results. Tables and figures use these same results. Numerical quadrature is evaluated at two resolutions.
7. **Made computational failures visible.** Convergence warnings terminate a run; nonfinite estimates are fatal. No failed replicate is silently excluded. Seeds are addressable by configuration and replicate and do not depend on scheduling. The actual environment is recorded.
8. **Corrected mathematical exposition.** At the boundary pi2=1, the two inverse-weighted increments combine; the full-data residual does not vanish. The variance gap is described as a first-order efficiency-bound comparison. Sequential MAR and unrestricted CCMAR are not called globally nested models. “Efficient score” terminology is replaced by influence-function terminology where appropriate.
9. **Aligned claims with evidence.** Removed statements asserting demonstrated consistency/rates, guaranteed interval calibration as sample size grows, unsupported clipping sensitivity, an established bootstrap remedy, or that all-oracle validation rules out every implementation error. The Gaussian stress design's undercoverage remains visible and is not presented as repaired by code corrections.
10. **Prepared the manuscript files.** Shortened the English abstract, added a French abstract, updated the results and Appendix D, provided complete figure/table inputs and source, and replaced the unverified claim of a public code repository with an accompanying-supplement statement.

The research question, principal influence-function and drift formulas, main variance-gap theorem, and existing authorship are retained. The added simulation design and rewritten interpretation should be reviewed by the author before submission.
